進度存在你自己 GitHub 帳號的私密 Gist，電腦、手機打開都是同一份。
  1. 打開 GitHub 建立 token（已幫你勾好 gist，其他都不用勾）
  2. Expiration 選 No expiration，按最下面 Generate token
  3. 複製 ghp_ 開頭那串，貼到下面按「連結」
  4. 每台裝置都貼同一個 token 一次就好；第一次連結會把這台跟雲端的進度合併

從高中 Level 1～6 和多益商務字各抽 15 個，加上 8 個不存在的假字，共 113 題，大約 5～7 分鐘。

看到字，一秒內想得出中文意思才按「會」。想不出來、只覺得眼熟、不確定，一律按「不會」。
對假字按「會」的次數會用來校正結果，亂按分數反而會被扣。
