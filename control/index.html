這門課到底在幹嘛：用冷氣來想

你把冷氣設 26°C。溫度計量到現在 30°C，差了 4 度，冷氣就開強一點。差越少就開越弱。這種「量結果、跟目標比、再修正」的架構就叫回授控制。整本講義都在研究這張圖：

藍色那條就是「回授」：把輸出量回來，跟目標相減。

整門課只在問三個問題：

問題冷氣版章節
① 會不會失控？開太猛，室溫忽冷忽熱越晃越大Ch4 穩定度
② 反應好不好？多快降到 26°C？會不會衝過頭降到 24°C？Ch5 暫態
③ 最後準不準？穩定後停在 26.5°C 還是剛好 26°C？Ch5 穩態誤差

其他章是工具：Ch2 拉氏轉換是數學工具；Ch3 把系統畫成圖再算成一個式子；Ch6 根軌跡看「旋鈕 K 越轉越大時」會怎樣；Ch7 波德圖是換一個角度看同一件事。

整門課最重要的一句話：把系統寫成一個分數 T(s)，分母 = 0 的根叫「極點」。極點的位置決定了上面三個問題的答案。後面每一章其實都在找極點、看極點。
CH 2

拉氏轉換：把微分變成乘法的翻譯機

系統的行為是用微分方程描述的（有 y′、y″ 那種），很難直接解。拉氏轉換把它翻譯成 s 的代數式，用國中代數解完，再查表翻回來。

翻譯規則只要記一條：微分一次 = 乘一個 s；積分一次 = 除一個 s。
另外常用的查表：u(t)（步階，一個從 0 跳到 1 的輸入）→ 1s；e−at → 1s+a
例題
解 y″ + 3y′ + 2y = u(t)，初始條件都是 0。
  1. 翻譯成 sy″→s²Y、y′→sY、y→Y、u(t)→1/s
    s²Y + 3sY + 2Y = 1s
  2. 用代數解出 Y把 Y 提出來，再把分母因式分解：
    Y = 1s(s² + 3s + 2) = 1s(s+1)(s+2)
  3. 拆成部分分式（遮蓋法）要拆成 As + Bs+1 + Cs+2。
    求 A：用手指蓋住分母的 s，剩下 1/((s+1)(s+2))，代 s=0 → A = 1/2
    求 B：蓋住 (s+1)，剩 1/(s(s+2))，代 s=−1 → B = 1/((−1)(1)) = −1
    求 C：蓋住 (s+2)，剩 1/(s(s+1))，代 s=−2 → C = 1/((−2)(−1)) = 1/2
  4. 查表翻回來1/s → 1、1/(s+1) → e−t、1/(s+2) → e−2t
    y(t) = 12 − e−t + 12e−2t
  5. 檢查t=0：½ − 1 + ½ = 0，符合初始條件。t→∞：指數都消失，剩 ½。下面就是它的圖。

y(t) = ½ − e−t + ½e−2t

從 0 慢慢爬到 0.5 停住。
注意到了嗎？答案裡的 e−t、e−2t 來自分母的根 s=−1、s=−2。這兩個就是極點。極點是負的，指數就會衰減，所以 y 會停下來。這就是 Ch4 穩定度的全部精神。
CH 3

轉移函數與方塊圖：把系統變成一個方塊

轉移函數 = 輸出 ÷ 輸入（都用 s 寫，初始條件當 0）。上一題 s²Y + 3sY + 2Y = U，所以

G(s) = YU = 1s² + 3s + 2

有了它，整個系統就是一個方塊：輸入乘上 G 就是輸出。很多方塊接在一起時：

接法結果白話
串聯（一個接一個）G₁ · G₂一路乘下去
並聯（分兩路再加起來）G₁ + G₂兩路相加
負回授G1 + GH考試最常用，一定要會推

回授公式怎麼來的（3 行）

  1. 比較器誤差 = 目標 − 量回來的：E = R − H·Y
  2. 前向路徑輸出 = G × 誤差：Y = G·E = G(R − HY)
  3. 移項Y + GHY = GR ⇒ Y(1 + GH) = GR ⇒ T = YR = G1+GH
例題
G = 10s(s+1)，H = 1（單位回授），求閉迴路轉移函數 T(s)。
  1. 套公式T = 10/(s(s+1))1 + 10/(s(s+1))
  2. 上下同乘 s(s+1)，把繁分數消掉T = 10s(s+1) + 10 = 10s² + s + 10

小技巧：單位回授時，T 的分母 = G 的分母 + G 的分子。s(s+1) + 10，一秒寫完。

Mason 公式：方塊圖太亂時的萬用解

方塊圖有好幾個迴圈、一步步化簡容易錯時，就用 Mason。看這個有兩個迴圈的例子：

  1. 找前進路徑（從 R 走到 Y，不走回頭路）只有一條：P₁ = G₁G₂
  2. 找所有迴圈（繞一圈回到原點，負回授要帶負號）內圈 L₁ = −G₂H₁；外圈 L₂ = −G₁G₂H₂
  3. 算 Δ兩個迴圈都經過 G₂，有碰到，所以沒有「互不接觸」的組合：
    Δ = 1 − (L₁ + L₂) = 1 + G₂H₁ + G₁G₂H₂
  4. 算 Δ₁把碰到路徑 P₁ 的迴圈刪掉。兩個迴圈都碰到，全刪光 → Δ₁ = 1
  5. 代入 T = P₁Δ₁ / Δ
    T = G₁G₂1 + G₂H₁ + G₁G₂H₂
一般化：Δ = 1 − (所有迴圈相加) + (兩兩互不接觸的迴圈乘積) − …。大部分考題迴圈都互相碰到，所以只要算到第一項，Δₖ 也常常就是 1。
CH 4

穩定度：極點在左邊就穩，在右邊就爆

Ch2 看到了：分母的根（極點）p 會在輸出產生一項 ept。極點是複數 p = σ ± jω 時，那一項長這樣：

eσt · cos(ωt)

σ（實部，左右位置）決定振幅變大還變小；ω（虛部，上下位置）決定晃多快。自己拉看看：

拖動極點的位置，看系統的反應

判定：
左圖：s 平面（淡紅色是右半面）。右圖：eσtcos ωt。
極點位置反應結論
全部在左半面（σ < 0）越來越小，最後停住穩定
在虛軸上（σ = 0）永遠一樣大地晃臨界穩定
有任一個在右半面（σ > 0）越晃越大，爆掉不穩定

Routh 表：不用解根，就知道右半面有幾個根

分母是三次、四次方程式時很難解。Routh 表只靠係數就能數出「右半面有幾個根」。

例題 1
s³ + s² + 2s + 8 = 0，右半面有幾個根？
  1. 前兩列：係數「跳著」填第 1 列放第 1、3 個係數，第 2 列放第 2、4 個。
    s³12
    s²18
  2. 算下一列：交叉相乘
    (左下 × 右上 − 左上 × 右下) ÷ 左下 = (1×2 − 1×8) ÷ 1 = −6
    最後一列 s⁰ 用同樣算法，會剛好等於最後一個係數 8。
    s³12
    s²18
    s¹−60
    s⁰8
  3. 只看第一欄，數變號次數1 → 1 → −6 → 8：正變負一次、負變正一次，共 2 次。所以右半面有 2 個根，系統不穩定。

    （驗算：它等於 (s+2)(s²−s+4)，根是 −2 和 0.5 ± j1.94，真的有兩個在右邊。）

例題 2（最常考：求 K 的範圍）
s³ + 2s² + 3s + K = 0，K 在什麼範圍內系統穩定？
  1. 建表
    s³13
    s²2K
    s¹(2·3 − 1·K)/2 = (6−K)/20
    s⁰K
  2. 第一欄全部要 > 0（不能變號）(6−K)/2 > 0 → K < 6；K > 0
    ⇒ 答案 0 < K < 6
  3. K = 6 會怎樣？s¹ 列變 0，系統剛好在虛軸上，會一直晃。拿上一列 2s² + 6 = 0 解出 s = ±j√3，晃動頻率 ω = √3 rad/s。
三次方程式秒殺：s³ + as² + bs + c 穩定 ⇔ 係數全正且 a·b > c。上一題 2·3 > K，一行就得到 K < 6。
CH 5

時間響應：反應多快、會不會衝過頭、最後準不準

把輸入突然從 0 變成 1（步階），看輸出怎麼追上去。大部分考題都是這個二階標準形：

T(s) = ωₙ²s² + 2ζωₙs + ωₙ²

只有兩個旋鈕，想成汽車避震器：

旋鈕意思調大會怎樣
ζ（阻尼比）避震器多「硬」比較不晃，但爬得比較慢
ωₙ（自然頻率）彈簧多「緊」整體變快

調 ζ 和 ωₙ，看步階響應

上圖淡色帶是 1 ± 2%，進入後不再出去的時間就是 tₛ。下左圖是兩個極點的位置：ζ 越小，極點越靠近虛軸，就越晃。
規格意思公式
Mₒ 最大超越量衝過頭多少 %e−πζ/√(1−ζ²)
tₚ 峰值時間衝到最高點的時間πωₙ√(1−ζ²)
tₛ 安定時間（2%）穩定在 ±2% 內的時間4ζωₙ
例題 1（正向：給 T 求規格）
T = 4s² + 2s + 4，求 Mₒ、tₚ、tₛ。
  1. 跟標準形對照係數常數項 ωₙ² = 4 → ωₙ = 2；s 的係數 2ζωₙ = 2 → ζ = 2/(2·2) = 0.5
  2. 代 Mₒe−π·0.5/√0.75 = e−1.81 ≈ 0.163 → 衝過頭 16.3%
  3. 代 tₚπ / (2·√0.75) = π / 1.732 ≈ 1.81 秒
  4. 代 tₛ4 / (0.5·2) = 4 秒
例題 2（反向：要求規格，求 K）
單位回授，G = Ks(s+2)。要讓超越量剛好 16.3%，K 要多少？
  1. 先算閉迴路分母 = G 的分母 + 分子：T = Ks² + 2s + K
  2. 16.3% 對應 ζ = 0.5（上一題剛算過；考試直接用 Mₒ 公式反解）
  3. 對係數2ζωₙ = 2 → ωₙ = 2；ωₙ² = K → K = 4

穩態誤差：最後差多少

誤差 = 想要的 − 實際的，等到穩定以後還剩多少。關鍵在 G 裡有幾個 1/s（叫做 Type 幾）。

直覺：1/s 是積分器，像一個會記帳的人：只要還有一點誤差，就一直累加、一直加大出力，直到誤差歸零。所以 G 裡有 1/s 的系統，追固定目標最後一定追得到。
例題
單位回授，G = 10s(s+2)。輸入是步階、以及斜坡 r = t 時，穩態誤差各是多少？
  1. 先確認穩定（一定要做！）閉迴路分母 s² + 2s + 10，二次式係數全正 → 穩定。不穩定的話後面全部不能算。
  2. 數 Type分母有 1 個 s → Type 1
  3. 步階輸入Kₚ = lims→0 G = 10/0 = ∞ → eₛₛ = 1/(1+Kₚ) = 0（追得到）
  4. 斜坡輸入Kᵥ = lims→0 s·G = lim 10/(s+2) = 5 → eₛₛ = 1/Kᵥ = 0.2（永遠落後 0.2）
Type步階 1/(1+Kₚ)斜坡 1/Kᵥ拋物線 1/Kₐ
0（沒有 1/s）有限值∞∞
1（一個 1/s）0有限值∞
2（兩個 1/s）00有限值

Kₚ = lim G，Kᵥ = lim sG，Kₐ = lim s²G（都是 s→0）。

CH 6

根軌跡：把旋鈕 K 越轉越大，極點怎麼跑

控制器的增益 K 就像冷氣的「強度旋鈕」。K 一改，閉迴路的極點就會移動，系統的行為跟著變。根軌跡就是把極點移動的路線畫出來。

拉 K，看極點怎麼移動

左：淡藍點是 K 從 0 到 12 所有極點走過的路（根軌跡），紅色 × 是目前 K 的極點。右：目前 K 的步階響應。
例題（系統 A，可以直接解根）
單位回授 G = Ks(s+2)，畫根軌跡。
  1. 閉迴路分母s² + 2s + K = 0 → 公式解 s = −1 ± √(1−K)
  2. K = 0s = 0, −2：就是 G 自己的極點。根軌跡從開迴路極點出發。
  3. 0 < K < 1根號裡是正的，兩個實數根，從 0 和 −2 往中間靠近。
  4. K = 1兩根在 s = −1 撞在一起，這叫分離點。
  5. K > 1根號裡變負，s = −1 ± j√(K−1)，沿著 Re = −1 的直線往上下分開。K 越大越晃，但永遠在左半面，永遠穩定。

考試不能直接解根時：用規則畫（拿系統 A 驗證）

規則做法系統 A
① 起點G 的極點（分母 = 0）0、−2 ✓
② 實軸上哪段有線某段右邊的極點＋零點總數是奇數0 到 −2 之間（右邊有 1 個）✓
③ 漸近線條數 = 極點數 − 零點數；角度 180°×(奇數)/(條數)；交點 (Σ極點 − Σ零點)/(條數)2 條、±90°、交在 (0−2)/2 = −1 ✓
④ 分離點把 K 解出來，對 s 微分 = 0K = −s²−2s，−2s−2 = 0 → s = −1 ✓
⑤ 穿過虛軸用 Routh 求臨界 K不會穿過（永遠穩定）
換系統 B 看看：3 個極點 → 3 條漸近線（±60°、180°），交在 (0−1−2)/3 = −1。分母 s³ + 3s² + 2s + K，三次秒殺 3·2 > K → K < 6 才穩定，K = 6 時在 ω = √2 ≈ 1.41 穿過虛軸。把滑桿拉過 6，右邊的圖就會爆掉。
觀念題：加一個極點（像 A→B）會把根軌跡往右推，系統比較容易不穩；加一個零點會把它往左拉，系統比較穩。
CH 7

頻率響應與波德圖：餵正弦波進去看看

換一種測法：輸入一個正弦波。線性系統的輸出還是同頻率的正弦波，只會改變兩件事：

  • 大小被放大或縮小：乘上 |G(jω)|
  • 時間被延遲：相位差 ∠G(jω)

波德圖 = 把每個頻率的「放大倍數」和「延遲角度」畫成兩張圖。放大倍數用 dB 表示：dB = 20 log₁₀|G|。

倍數1010.7070.10.01
dB+200−3−20−40

G(s) = 1/(1+s)：調輸入頻率 ω

上：灰色是輸入，紅色是輸出（橫軸以週期為單位）。下：波德大小圖、相位圖，紅點是目前的頻率。

拉一拉你會發現：低頻時輸出跟輸入幾乎一樣；到 ω = 1（轉角頻率）時剩 0.707 倍（−3 dB）、慢 45°；再往高頻，頻率每乘 10，輸出就變成 1/10（−20 dB），延遲趨近 90°。這就是講義說的「−20 dB/decade」。

例題：畫波德大小圖
G(s) = 100(s+1)(s+10)
  1. 改寫成「1 + s/轉角」的形式把 (s+10) 寫成 10(1 + s/10)：
    G = 10010(1+s)(1+s/10) = 10(1+s)(1+s/10)
  2. 低頻高度前面的常數 10 → 20 log 10 = 20 dB，先畫一條 20 dB 的水平線。
  3. 找轉角(1+s) 的轉角在 ω = 1；(1+s/10) 的轉角在 ω = 10。
  4. 每過一個分母的轉角，斜率就 −20 dB/decω < 1：水平 20 dB。1 到 10：−20 dB/dec，到 ω=10 掉到 0 dB。> 10：−40 dB/dec，到 ω=100 掉到 −40 dB。

折線（虛線）＝ 手畫的近似，實線 ＝ 真正的曲線

反過來就是「系統鑑別」（Ch7 最後一節）：看圖找出斜率在哪裡轉彎，就知道分母有哪些 (1+s/轉角)；看低頻高度就能算出前面的常數。
